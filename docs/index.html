Features

Everything Estuary has, rebuilt

Designed for use with the FEN family of add-ons (Fen Light, Red Light, The Gears, Umbrella, POV, TMDbH).

Modern UI

A redesigned experience built on Kodi's Estuary skin.

Extra viewtypes

"WideWall" and "WideInfoWall" plus tuned built-in views.

Customizable widgets

Movie, TV-show and episode widgets, including stacked category widgets.

Custom main menu

Configurable movie and show menu items and paths.

Ratings and InfoPanel

Ratings for movies, shows, seasons and episodes, with an optional InfoPanel.

Digital release dates

Movies show a Digital Release date in the InfoPanel via a free MDbList key. Setup

Multi-search

Search several categories at once, including Trakt lists.

Unwatched progress

TV thumbnails show unwatched and total episodes at a glance.

Auto-updates

Install the repository once and stay up to date automatically.

Install

Install from the repository

This skin depends on the script.fentastic.helper add-on. Installing the FENtastic Plus repository below resolves that dependency automatically and keeps everything updated afterward.

  1. Download repository.fentastic-x.x.x.zip from the Releases page onto the device running Kodi.
  2. In Kodi: Settings → Add-ons → Install from zip file, browse to where you saved it, and install it.
  3. Install from repository → FENtastic Plus Repository → Look and feel → Skin → FENtastic Plus → Install. Kodi resolves the script.fentastic.helper dependency from the same repository automatically, so no separate helper install is needed.

If Kodi blocks the install, enable Settings → System → Add-ons → Unknown sources (on some builds this is under Settings → Add-ons directly). Once installed, Kodi will keep both the skin and the helper updated automatically whenever a new version is released.

Updating

Kodi checks the repository for new versions on its own schedule, and on some networks that background check can time out and get stuck. If a new version doesn't show up after a release, force it manually: Settings → Add-ons → My add-ons → Look and feel → FENtastic Plus Repository → open it (or right-click it and choose Check for updates). This pulls the current addons.xml immediately instead of waiting on Kodi's background check.

Optional setup

Ratings and digital release dates

Movie and show ratings and, for movies, a Digital Release date in the InfoPanel are both powered by the free MDbList API. Without a key the skin works normally; it just won't show ratings or a digital release date.

  1. Create a free account at mdblist.com and generate an API key from your preferences page. The free tier covers normal skin use (1000 requests a day) and costs nothing.
  2. In Kodi, open Configure skin… → Settings → Ratings/Trailers → Enter MDbList API Key and paste it in.
  3. That's it. Ratings populate automatically as you browse, and movies with a known digital or streaming release show it right under the release year in the InfoPanel.

You can turn off individual rating sources (Metacritic, Rotten Tomatoes, IMDb, TMDb) from the same settings tab if you only want the digital release date.
